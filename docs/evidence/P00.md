## What the transcript covers

The transcript below is a clone of `8ef8fbd`, the parent of the P00-GATE commit, because a commit
cannot contain a transcript of verifying itself. It therefore exercises the repository **without**
`test/contract/m0-gate.test.ts`. After the P00-GATE commit exists, the same sequence was re-run
against it and is reported in the task report; `pnpm check` includes the gate cases from then on.

`corepack enable` was not run inside the clone: `corepack enable` writes into the Node
installation, which is read-only in this sandbox. The clone used the pinned pnpm 10.34.9 that is
already active, which is what `corepack enable` would have selected.

```text
$ git clone <repo> /tmp/fl-m0 && cd /tmp/fl-m0
HEAD: 8ef8fbd

$ pnpm install --frozen-lockfile        exit 0   2 s   "Done in 1.9s using pnpm v10.34.9"
$ pnpm check                            exit 0  14 s
$ pnpm test:integration                 exit 0   5 s
$ pnpm test:e2e                         exit 0   1 s
$ pnpm test:performance                 exit 0   0 s   "test:performance: not implemented until P12"
$ pnpm db:up                            exit 0   6 s   flowledger-postgres-1 Healthy
```

## Known gaps at M0

1. **No observed CI run.** The workflow is validated statically (actionlint) and its commands were
   executed locally, but GitHub Actions has not run it. Pending the first push.
2. **`test:performance` does nothing.** It prints and exits 0 by design; P12 replaces the file.
3. **Terraform version not recorded.** No Terraform exists at M0.
4. **The `flowledger` bin needs two installs on a fresh clone** (pnpm links the shim only once
   `apps/cli/dist/index.js` exists). Documented in `docs/DEVELOPMENT.md`; the code-side fix needs a
   plan amendment and is not applied.
5. **`fee_policies_minimum_capture`** remains a redundant CHECK alongside
   `fee_policies_fee_within_minimum`; kept deliberately as defence in depth (P02-T07 notes it).
